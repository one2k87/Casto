# S1 EP3 「택배 왔습니다」 비트 시트 (초안 2026-11-23, 승인 전 — 그림 생성 전)

- 길이 약 68초 · 컷 27개 · 소리는 3화 전용 로파이만 · 내레이션은 자막(ko·en·ja·es)
- 2화에서 이어짐: 산 쪽으로 달리는 냉동 트럭 짐칸, 어둠 속 눈 두 개.
- 이번 화 목표: 눈의 주인(햄스터 택배원 콩)과 친구가 된다 → (방해) 서툰 배달 소동 → (전환) 집이 어딘지 아무도 모른다 → (클리프) 밀린 소포의 송장에 펭귄 발자국.
- 발명품: 햄스터 볼주머니 택배(볼에서 꺼내면 젖어 있음) · 거북이 택배 트럭(새로 추가 — 늘 늦는 이유).
- 콩: 버터색 택배 모자, 성실한데 한 박자 늦음, 볼주머니에 택배를 넣었다 꺼냄. 시즌 2 주인공이라 이번 화에서 호감을 쌓는다.
- 앞 화와 짝을 이루는 장면: 냄새를 따라감(1화) ↔ 찬 김을 따라감(2화) ↔ 생선 굽는 연기를 따라감(3화 끝).
- 예상 비용: 그림 27장 × 0.25 + 영상 4초 4 = 약 10.75크레딧(충전분). 생성 직전에 견적을 다시 확인한다.
- 실험 변수: 2화 게시 24시간 수치를 본 뒤 확정(후보: 올리는 시각 / 제목 형식). 콜드 오픈은 2화와 같게 둔다.

## 확인할 점
- 2화 24컷에서 택배 모자 그림자가 밖에서 문을 닫았는데 3화에서 콩이 짐칸 안에 있다 → 1컷 자막에 "문을 닫고 올라탄 건 택배원이었습니다"를 넣어 잇는다.
- 거북이 택배 트럭을 발명품 도감에 추가한다(콘티 작성 때).
