# 상품 사진 보관함

**여기 들어오는 것은 실제 상품 사진뿐입니다.** 제품을 AI로 재현한 이미지는 쓰지 않습니다 —
실물과 다른 그림은 시청자가 즉시 알아채고 돌아섭니다. 사진이 없으면 제품 이미지 없이 나갑니다.

## 넣는 법

`캡처_넣는곳/` 폴더에 **파일 이름을 제품 이름으로** 해서 넣으세요. 나머지는 코드가 합니다.
자세한 규칙은 `캡처_넣는곳/README.md` 참조.

## 허용 출처

1. **직접 캡처** — 쿠팡 상품 페이지의 대표 이미지 (`image_source: capture`)
2. **쿠팡 파트너스 링크 생성 화면에서 저장한 공식 이미지** (`coupang_partners`)
3. **픽담 글의 KOKPICK 블록 이미지** — 자동 캐시 (`pickdam`)

## 금지

- 제품의 AI 가상 재현
- 다른 유튜버 썸네일, 인스타 릴스 캡처, 검색 이미지 저장 (저작권)
