# 상품 사진 보관함

여기 들어오는 사진은 **두 출처만** 허용한다.

1. **쿠팡 파트너스에서 받은 공식 상품 이미지** — 파트너스 링크 생성 화면에서 저장.
   (파트너스 회원이면 수익이 없어도 이 화면은 쓸 수 있다. 수익 조건이 걸린 건 Open API 쪽이다.)
2. **픽담이 자기 글에 올린 이미지** — `catalog.py`가 KOKPICK 블록의 `image_url`로 자동 캐시.

절대 금지: 다른 유튜버 썸네일, 인스타 릴스 캡처, 검색 이미지 저장. 저작권 침해이고 채널이 위험해진다.

파일명은 `data/catalog.json`의 slug와 같게 두면 관리가 쉽다.
예) `테팔-티타늄-언리미티드-28cm.jpg`
