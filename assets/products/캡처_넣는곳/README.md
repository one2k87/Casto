# 여기에 상품 캡처를 넣어주세요

**규칙은 하나입니다 — 파일 이름을 제품 이름으로 저장하세요.**

```
assets/products/캡처_넣는곳/
├─ 락앤락 접이식 실리콘 밀폐용기 800ml.png
├─ 3M 레이저가이드 주방가위.jpg
└─ 코멧 쌀통 10kg.png
```

넣고 나서 `python capture_import.py` (또는 그냥 커밋만 해도 매일 워크플로가 처리)
→ 파일이 `assets/products/`로 옮겨지고 `data/catalog.json`에 등록됩니다.
→ 그 다음부터 그 제품 영상은 **캡처한 실제 사진**으로 나갑니다.

## 캡처 팁

- 쿠팡 상품 페이지의 **대표 이미지 1장**이면 충분합니다. 배경이 흰색이면 자동으로 누끼가 됩니다.
- 가격표·별점·쿠팡 UI는 빼고 **제품만** 나오게 잘라주세요.
- 정사각형에 가까울수록 카드에 예쁘게 들어갑니다.
- 파일 이름에 브랜드명을 넣으면 영상 자막에도 그 이름이 그대로 나갑니다.

## 절대 하지 않는 것

- **제품을 AI로 재현하지 않습니다.** 가상 이미지는 시청자가 즉시 알아채고 돌아섭니다.
  실제 사진이 없으면 제품 이미지 없이 클레이 콕이만 나갑니다 — 없는 게 가짜보다 낫습니다.
- 다른 크리에이터의 썸네일·릴스 캡처는 쓰지 않습니다(저작권).
