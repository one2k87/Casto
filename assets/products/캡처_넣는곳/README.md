# 여기에 상품 캡처를 넣어주세요

**`_목록.html`을 더블클릭하세요.** 브라우저로 열리고, 버튼을 누르면 상품 페이지로 바로 갑니다.
(`_목록.md`는 같은 내용의 텍스트 버전입니다.)

```
3번  늘어나는 밀폐용기   →   3.png  (또는 3.jpg)
```

파일을 이 폴더에 넣고 커밋만 하시면 됩니다. 나머지는 전부 코드가 합니다 —
번호 → 제품 매칭, 카탈로그 등록, 파일 이동, 배경 누끼, 카드 배치, 자막 이름 반영.

브랜드·모델을 정확히 아시면 `3 락앤락 밀폐용기 800ml.png` 처럼 **번호 뒤에 이름**을 붙이셔도 됩니다.
그때는 적어주신 이름이 영상 자막에 그대로 나갑니다.

## 캡처 팁

- 쿠팡 상품 페이지의 **대표 이미지 1장**이면 충분합니다. 배경이 흰색이면 자동으로 누끼가 됩니다.
- 가격표·별점·쿠팡 UI는 빼고 **제품만** 나오게 잘라주세요.
- 정사각형에 가까울수록 카드에 예쁘게 들어갑니다.

## 번호 규칙

- 번호는 **한 번 붙으면 바뀌지 않고, 완료된 번호는 다시 쓰이지 않습니다.**
  어제 3번을 보고 캡처해 둔 것이 오늘 다른 제품의 3번이 되는 사고를 막기 위해서입니다.
- 영상이 만들어질 때 사진이 없으면 **텔레그램으로 "N번 저장해주세요"** 가 옵니다.

## 절대 하지 않는 것

- **제품을 AI로 재현하지 않습니다.** 실물과 다른 그림은 시청자가 즉시 알아채고 돌아섭니다.
  사진이 없으면 제품 이미지 없이 클레이 콕이만 나갑니다 — 없는 게 가짜보다 낫습니다.
- 다른 크리에이터의 썸네일·릴스 캡처는 쓰지 않습니다(저작권).

## 폰에서 바로 등록하기 (2026-09-09 신설 · 권장)

이 폴더에 파일을 직접 넣지 않아도 됩니다. **앱에서 📷 버튼**을 누르면
촬영/선택 → 자르기 → 등록까지 폰 안에서 끝나고, 깃허브가 자동으로 반입합니다.

1. 앱 열기 → https://one2k87.github.io/Casto/dashboard/
2. 처음 한 번만: 우측 상단 **⚙ → 깃허브 토큰 저장**
   - 토큰 만들기: https://github.com/settings/personal-access-tokens/new
   - Repository access = **one2k87/Casto** 하나만
   - Permissions = **Contents: Read and write**
   - 토큰은 그 폰에만 저장되고 서버로 전송되지 않습니다.
3. 번호표에서 🛒로 쿠팡을 열어 상품 화면을 캡처 → 앱으로 돌아와 **📷 → 사진 선택**
4. 모서리를 끌어 **제품만 남기고** → **등록**

등록하면 `capture-import` 워크플로가 자동으로 돌아 카탈로그에 반영하고
텔레그램으로 "등록 N건 · 남은 캡처 M건"을 보냅니다.
