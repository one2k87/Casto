### 여기서 나오는 규칙 3개

**R1. 도달은 묶음에서 나온다.** 100만 넘는 건 전부 2~3개 묶음이다.
단일 상품 심사 포맷은 이 니치에 사실상 존재하지 않는다. 1판이 거기 있었다.

**R2. 인과는 훅이 아니라 본론이다.** 추상적 "왜 유행이 생길까"는 1천대에서 죽는다.
**구체적인 그 물건**에 붙었을 때만 산다(리센느 25만). 그러므로 훅은 물건이고,
인과는 물건을 붙잡은 다음에 푸는 깊이다. 순서를 바꾸면 죽는다.

**R3. 제목에 브랜드명을 나열하면 죽는다** (2.7천). 브랜드는 화면 안에서 말하고,
제목은 **숫자 + 후회/발견 프레임 + 사회적 증거**로 간다.
- 숫자: `3가지` `Best3` `TOP3`
- 후회/발견: `진작 살걸` `돌고돌아` `어쩐지 많이 보이더라`
- 사회적 증거: `친구들이 물어보는` `엄마가 어디서 샀냐며` `해외에서 난리난`
- 개수는 **3이 최적**이다. 4는 9.2천으로 떨어진다.

## 2. 새 포맷 「왜 갑자기 보이지?」 — 30초

**한 줄 규칙: 3개를 몰아서 보여주되, 콕 도장은 하나만 찍힌다.**

묶음의 도달력(R1)과 미결 서사(끝까지 봐야 어느 게 콕인지 안다)를 동시에 가진다.
브랜드 언어(오늘의 콕 / 조건콕 / 다음콕)는 1판 그대로 살린다 — 바뀌는 건
심사 대상이 *상품 1개의 근거 3줄*에서 *상품 3개 중 1개 선정*으로 옮겨간 것뿐이다.

| 초 | 화면 | 목적 |
|---|---|---|
| 0–3 | **물건 3개가 우르르 쏟아진다** + 자막 "이번 주 갑자기 많이 보이는 것 3" — 실사진, 움직임 즉시 | 시각형 훅(R2: 물건이 먼저) |
| 3–5 | 콕이 등장(돋보기) — "왜 갑자기?" | 캐릭터 · 질문 세팅 |
| 5–13 | **① 물건** — 실사진 + **인과 만화 2컷** + 한 줄 자막 | 왜 유행인가 |
| 13–21 | **② 물건** — 같은 구조 | |
| 21–28 | **③ 물건** — 같은 구조 | |
| 28–32 | 콕이가 셋 중 **하나에만 도장** — "오늘의 콕 ✅" / 나머지는 다음콕 📦 | 미결 해소 · 구매욕 |
| 고정 | 설명란: 쿠팡 링크 3개 + 픽담 + 대가성 문구 | 수익 |

### 인과 만화 2컷이 이 포맷의 심장이다

사용자 예시 그대로:

> 컷1: 두바이 초콜릿 / 두쫀쿠가 유행 → 컷2: 피스타치오 수요 폭증 → **그래서 이게 보인다**

글로 "피스타치오가 유행입니다"라고 쓰면 아무도 안 본다. **원인 → 결과**를 그림 두 장으로
보여주면 시청자가 "아 그래서"를 경험한다. 그 경험이 이 채널의 차별점이고,
묶음 영상이 못 하는 유일한 것이다.

만화 컷 규칙:
- **컷1 = 원인**(무엇이 먼저 유행했나 / 어떤 상황이 생겼나)
- **컷2 = 결과**(그래서 이 물건 수요가 어떻게 됐나)
- 말풍선 최대 6글자. 나머지는 그림으로.

### ⚠️ 절대 규칙 — 상품은 만화로 그리지 않는다

> "절대로 제품을 가상으로 재현하면 안 돼. 그 즉시 시청자는 바로 돌아설 거야." — 2026-09-08

| 대상 | 표현 |
|---|---|
| **상품 자체** | **실사진만**. 없으면 화면에 안 낸다(catalog.render_mode 3단계 그대로) |
| 유행의 원인·상황 | 만화 ✅ (두바이 초콜릿, 사람, 매대, 검색 그래프 등) |
| 콕이 | 클레이 캐릭터 ✅ |

만화가 상품 모양을 그리는 순간 1판의 `ai_render` 금지와 같은 위반이다.
코드에서 테스트로 잠근다.
