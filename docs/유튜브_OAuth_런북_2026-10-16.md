# 유튜브 소유자 토큰 발급 런북 (1회, 약 10분)

왜: Make의 유튜브 업로드가 간헐적으로 403을 내며 제목 `unknown` 공개 영상을 남긴다(10/13·10/15 네 편).
Make 커뮤니티에 2025-10부터 같은 보고가 있고 원인 미상 — Make 쪽 수정을 기다릴 수 없다.
해법: **업로드는 Make가 하고, 뒤처리는 우리가** 한다. 채널 소유자 토큰이 있으면 publish.py가 좀비를 찾아
오늘 편의 제목·설명·태그를 붙여 정상 발행으로 되살리고(403이 나도 발행은 된다), 중복은 비공개로 돌린다.
같은 토큰으로 YouTube Analytics API도 열린다(정체성 실험 자동 측정 — 사람 손 하나 더 줄어든다).

famto는 키·토큰을 만지지 않는다. 아래는 사용자가 하는 클릭 경로.

## 1. Google Cloud 프로젝트에 YouTube API 켜기 (3분)

1. https://console.cloud.google.com 접속 → 상단 프로젝트 선택 → **AI Studio 키(LLM_API_KEY)가 있는 프로젝트** 선택
   (프로젝트 이름은 https://aistudio.google.com/api-keys 표에서 확인).
2. 왼쪽 메뉴 **API 및 서비스 → 라이브러리** → "YouTube Data API v3" 검색 → **사용**.
   같은 방법으로 "YouTube Analytics API"도 **사용**.

## 2. OAuth 동의 화면 (3분)

1. **API 및 서비스 → OAuth 동의 화면**(또는 "Google Auth Platform → 브랜딩").
2. 처음이면: 앱 이름 `Casto`, 사용자 지원 이메일 = 본인, 대상 **외부(External)**, 개발자 연락처 = 본인 → 저장.
3. **대상(Audience)** 탭 → 게시 상태가 "테스트"면 **「앱 게시」**를 눌러 **프로덕션**으로. 확인 창은 그냥 확인.
   (테스트 상태면 토큰이 7일마다 죽는다 — 반드시 프로덕션. "확인되지 않은 앱" 경고는 본인만 쓰므로 무시해도 된다.)

## 3. OAuth 클라이언트 만들기 (2분)

1. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**.
2. 애플리케이션 유형 **데스크톱 앱**, 이름 `casto-desktop` → 만들기.
3. **JSON 다운로드** → 파일을 `~/Downloads/client_secret.json` 으로 둔다(아무 데나 OK, 경로만 기억).

## 4. 토큰 발급 (2분, 터미널)

```
cd ~/Desktop/SolvUp_Workspace/Casto
python3 yt_auth.py ~/Downloads/client_secret.json
```
- 브라우저가 열린다 → **콕픽 채널이 있는 계정**으로 로그인. 계정 고르는 화면에서 **브랜드 계정(픽핸드 / 콕픽)** 이 따로 보이면 그걸 고른다
  (Make 연결이 그 계정이다). "확인되지 않은 앱" 화면이 나오면 **고급 → Casto(으)로 이동** → 권한 허용.
- 터미널에 `YT_CLIENT_ID` / `YT_CLIENT_SECRET` / `YT_REFRESH_TOKEN` 세 줄이 찍힌다.

## 5. GitHub Secrets 등록 (2분)

GitHub → Casto 저장소 → Settings → Secrets and variables → Actions → **New repository secret** ×3:
`YT_CLIENT_ID`, `YT_CLIENT_SECRET`, `YT_REFRESH_TOKEN` (터미널에 찍힌 값 그대로).

끝. famto에게 "유튜브 토큰 넣었어" 한 줄. 그러면:
- `data/publish_hold.txt` 보류가 **자동 해제**된다(토큰이 있으면 publish.py가 보류를 무시한다 — 파일은 famto가 지운다).
- 다음 발행일부터 Make가 403을 내도 좀비가 자동으로 오늘 편이 된다. 텔레그램엔 평소처럼 링크가 온다.

## 6. 하지 않아도 되는 것

- Google의 **YouTube API 감사(audit) 신청** — 직접 업로드를 공개로 하려면 필요하지만, 위 방식(Make 업로드 + 우리 수리)은 감사 없이 된다.
  나중에 Make를 완전히 빼고 싶을 때 신청한다(무료, 2~3주).
- client_secret.json 을 저장소에 넣는 일 — 절대 금지. 토큰 발급 뒤 파일은 지워도 된다.
