# 콕픽 하루 10분 루틴 (2026-09-10 확정)

작업 시간대는 **20:00~24:00 KST**. 그 앞 시간에 자동 작업이 전부 끝나 있으므로,
사람이 하는 일은 **앱을 열고 「다음 할 일」 하나를 처리하는 것**뿐이다.

## 요일별 — 발행일에만 손이 간다

| 요일 | 사람이 하는 일 | 시간 |
|---|---|---|
| 월 | 없음 (자동 수집·집계) | 0분 |
| **화** | **영상 업로드 1편** | 3분 |
| 수 | 캡처가 밀렸으면 2~3건 | 0~3분 |
| 목 | 없음 | 0분 |
| 금 | 쿠팡 링크가 밀렸으면 2~3건 | 0~3분 |
| **토** | **영상 업로드 1편** | 3분 |
| 일 | 없음 | 0분 |

주 2편 램프업 기준이다. 스냅샷 7일이 모이면 주 4편(월·화·목·토)으로 자동 전환되고,
그때도 편당 3분이라 하루 10분을 넘지 않는다.

## 업로드 3분 — 앱이 대신하는 부분

1. 텔레그램에서 mp4 저장 (30초)
2. 앱 「🎬 오늘 업로드」 카드 → **📋 제목** → 유튜브 스튜디오에 붙여넣기
3. 앱으로 돌아와 **📋 설명** → 붙여넣기
4. 공개 → 앱에서 **업로드 완료로 표시**

제목·설명을 텔레그램에서 긁어 옮기던 것이 매일 가장 오래 걸리는 손작업이었다.
`make_short`가 `data/last_caption.json`에 남기고 앱이 한 번에 복사한다.

## 캡처 1분 — 사진첩을 거치지 않는다

번호표에서 🛒 → 쿠팡 화면 캡처 → **복사 후 삭제** → 앱 📷 → 📋 붙여넣기 → 자르기 → 등록.
등록하면 깃허브가 자동 반입하고 텔레그램으로 결과를 보낸다.

## 링크 1분 — 채널을 지정해서 만든다

파트너스에서 상품 검색 → 링크 생성 시 채널 **`kokpicktube`** 선택 → 복사 →
앱 「🔗 쿠팡 링크 필요」에서 📋. 픽담용이 필요하면 같은 화면에서 채널만 `pickdamblog`로 바꿔 한 번 더.

## 남은 자동화 (조건이 풀리면 켠다)

| 항목 | 조건 | 효과 |
|---|---|---|
| 링크 자동 생성 | 파트너스 **최종 승인 → 오픈 API 키** | 링크 작업 0분. deeplink API가 subId(채널)까지 지원 |
| 영상 자동 업로드 | 유튜브 **OAuth 리프레시 토큰** 1회 발급 | 업로드 3분 → 0분. 하루 할 일이 '확인'만 남는다 |
| 실제 시청 지속률 학습 | 같은 OAuth (Analytics API) | 참여율 대리 지표를 진짜 retention으로 교체 |

세 개가 다 켜지면 사람이 하는 일은 **캡처뿐**이고, 그것도 새 유행템이 나올 때만이다.
