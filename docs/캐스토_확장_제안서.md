## 1. 쿠팡 수익 전략 — API 전 / 후 2단계

수익 구조의 핵심 제약: **인스타 릴스 캡션의 링크는 클릭이 안 되고**, 유튜브 쇼츠는 설명란·고정댓글 링크가 클릭된다. 그리고 파트너스 딥링크를 영상마다 수동 생성하는 순간 "완전 자동"이 깨진다. 그래서 1단계의 원칙은 하나다.

### 1단계 · API 전 (지금~첫 수익 15만원): "링크는 픽담이 만든다"

모든 영상의 CTA를 **픽담으로 수렴**시킨다. 영상은 궁금증을 만들고, 클릭·구매 전환은 파트너스 위젯·링크가 이미 깔린 픽담 글이 담당한다. 영상마다 딥링크를 만들 필요가 없어 자동화가 유지되고, 어느 플랫폼이든 링크 정책 제약을 우회한다.

- 유튜브: 설명란+고정댓글에 해당 픽담 글 URL(캐스토가 자동 삽입 — 원본 글 링크를 이미 캡션에 넣고 있음). 주력 글 3~5개만 파트너스 숏링크를 수동 생성해 별도 삽입.
- 인스타: 프로필 링크 = 픽담 홈(또는 링크트리형 페이지를 픽담에 자체 제작 — /links 페이지, 외부 서비스 불필요). 릴스 캡션엔 "프로필 링크 → 오늘 제품 비교". 스토리에는 링크 스티커로 글 직링 가능.
- 필수 준수: 영상 설명·픽담 글 모두에 대가성 문구("이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다") — 캐스토 캡션 생성기에 자동 포함시킨다.
- 파트너스 ID(AF코드)는 Picto 설정의 전용 필드에 저장 → 픽담 글 위젯·링크 삽입에 사용.

### 2단계 · API 후 (30일 확정수익 15만원 달성 시): "링크도 기계가 만든다"

- 오픈 API로 **상품 검색·딥링크 자동 생성** → 캐스토가 영상별 최적 상품 딥링크를 뽑아 Make를 통해 유튜브 설명란·고정댓글에 자동 삽입.
- 픽토(상품 선정 엔진) 가동: 카테고리 베스트셀러·로켓배송 필터·가격 변동을 API로 실측 → "오늘 팔 제품"을 데이터로 선정 → 글·영상 소재가 실판매 데이터 기반이 된다.
- 전환 흐름이 "영상 → 픽담 → 쿠팡"에서 "영상 → 쿠팡 직행"으로 단축(클릭 손실 감소).
- 1단계의 픽담 수렴 구조는 유지 — 검색(블로그)과 소셜(영상)의 이중 유입은 계속 가져간다.

## 2. 플랫폼별 전략 — 같은 소재, 다른 문법

### 유튜브 쇼츠 — "판정·비교" (검색되는 쇼츠)
유튜브는 검색+추천이 함께 도는 유일한 쇼츠 플랫폼. 구매 직전 검색("음식물처리기 비교")에 걸리는 **판정형 콘텐츠**가 팔린다.
- 콘텐츠: 45초 · 결론 먼저("4인 가구면 이거 삽니다") → 근거 3개(가격·스펙·조건분기) → 픽담 CTA
- 제목: 검색어 포함 문장형("음식물처리기 3년 쓰면 얼마? 계산해봤습니다")
- 팔리는 이유: 시청자가 이미 '살까 말까' 단계 — 정보 밀도가 전환을 만든다

### 인스타 릴스 — "감각·저장" (모아두고 싶은 쇼츠)
인스타는 검색이 아니라 **저장·공유**로 퍼진다. 정보를 압축한 심미적 카드·시네마틱이 저장을 부르고, 저장이 도달을 키운다.
- 콘텐츠: 20~30초 · 텍스트 최소 · 힉스필드 시네마틱 비주얼 중심 · "저장해두세요" 유도(예: 이사 전 체크 5, 자취 첫 살림 리스트)
- 캡션: 첫 줄 훅 + 해시태그 + "프로필 링크"
- 팔리는 이유: 저장 리스트를 실행할 때(이사·입주·자취 시작) 프로필 링크를 타고 들어온다 — 늦은 전환, 높은 단가

### 추가 추천: 네이버 클립 — "한국 커머스의 숨은 직결로"
- 같은 세로 영상을 재업로드만 하면 되고(추가 제작 0), **네이버 검색·쇼핑 지면에 노출**된다. 커머스 의도 트래픽 밀도가 셋 중 가장 높고 경쟁은 가장 낮다. 블로그(픽담 서치어드바이저 등록)와 같은 네이버 생태계 시너지.
- 틱톡은 보류: 링크 제약이 크고 쿠팡 전환 경로가 약함 — 채널이 자리 잡은 뒤 재검토.

### 채널명 (간결·언어유희) — 추천안

| 후보 | 유희 | 적합 |
|---|---|---|
| **사요마요** ★주력 | "사요? 마요?" — 구매 판정 그 자체가 이름 | 유튜브 채널명. 핸들 @sayomayo |
| **담아봄** | 장바구니에 담아봄 + 픽'담' 패밀리 연결 | 인스타 이름. 핸들 @damabom.pick |
| 사도될각 | "사도 될 각" | 예비(시리즈명으로 활용: '사도될각 판정') |
| 픽하는집 | pick+집(살림) | 예비 |

- 운영안: 유튜브 「사요마요」 / 인스타 「담아봄 | 살림 사요마요」 / 네이버 클립 「사요마요」 — 시리즈 명칭과 판결 멘트("오늘의 판정: 사요/마요")를 브랜드 자산으로 통일.

### 채널 세팅 가이드 (개설 시 체크리스트)
1) 유튜브: 브랜드 계정으로 채널 생성 → 핸들 @sayomayo → 채널아트(딥그린, "사는 게 고민될 땐, 사요마요") → 정보란에 픽담 링크+대가성 문구 → 업로드 기본값: 설명 템플릿·'아니오, 아동용 아님' 설정
2) 인스타: **프로페셔널(비즈니스) 계정으로 전환**(Make 자동 게시의 필수 조건) → 페이스북 페이지 연결 → 프로필 링크 = 픽담 /links → 하이라이트: 판정 모음
3) 네이버 클립: 네이버 크리에이터 등록 → 픽담 블로그와 동일 계정 운영
4) 공통: 프로필 아이콘은 픽토 집게 로고의 변형(사요마요 버전은 ⚖️ 저울+장바구니 모티프로 제작해드림)

## 3. 완전 자동화 아키텍처 — 힉스필드 × 캐스토 × 메이크

```
[주 1회] 트렌드 스캔(가동 중) ─→ trends.json (이번 주 훅·형식)
[매일 07:00] Picto: 픽담 글 발행 (가동 중)
[매일 08:00] Casto v1:
   글 → 대본(트렌드 주입, 컨셉 프롬프트)
     → 🎥 힉스필드 API: 씬별 시네마틱 클립 생성(image-to-video, 웹훅 수신)
     → 🎙 TTS 내레이션(현행 무료; 품질 업그레이드 시 일레븐랩스 스위치만 교체)
     → 🎵 BGM: 수노로 미리 만든 10곡 라이브러리 로테이션(assets/bgm — API 불필요)
     → ffmpeg 합성: 유튜브판(45s 판정형) + 인스타판(25s 저장형) 2벌 렌더
     → 완성 mp4를 픽담 미디어에 업로드(공개 URL 확보) → Make 웹훅 호출
[Make 시나리오] 웹훅 수신
     → YouTube: 자동 업로드(제목·설명·태그·고정 링크)
     → Instagram: Reels 자동 게시(비즈니스 계정)
     → 텔레그램: 결과 보고(네이버 클립은 주 2~3회 수동 재업로드, v2에서 자동화 검토)
```
- 안전장치: 힉스필드 생성 실패·크레딧 소진 시 현행 카드 스타일로 자동 폴백(발행 중단 없음). 크레딧은 만료형이므로 일일 소비량을 casto.json에서 제한.
- 사람 개입 0 목표 — 예외는 네이버 클립 재업(1분)과 주간 품질 리뷰뿐.

### 🌟 신규 컨셉 발굴 — "사물의 속마음" (어디에도 없는 포맷)
제품을 리뷰하는 사람은 넘친다. **제품이 직접 고백하게 한다.**
- 포맷: 힉스필드 시네마틱으로 의인화된 제품이 1인칭 고백 — "저는 음식물처리기입니다. 솔직히 말할게요, 원룸에서 저를 사시면 후회합니다…" → 자기 단점·경쟁 제품·맞는 사람 조건을 스스로 폭로 → 마지막 판정 자막 "오늘의 판정: 조건부 사요"
- 왜 새로운가: 리뷰(3인칭)도 브이로그(1인칭 사람)도 아닌 **1인칭 사물 고백체**. 힉스필드의 시네마틱 카메라 무빙(제품 클로즈업→고백 무드)이 스마트폰 촬영으론 불가능한 룩을 만든다. 신뢰 포인트: 단점을 제품이 먼저 말하므로 광고 냄새가 역전된다 — '경험담 창작 금지' 원칙과도 충돌 없음(스펙·공식 정보만 발화).
- 인스타 변형: 고백의 하이라이트 1문장 + 시네마틱 비주얼 = "저장하고 싶은 제품의 진심" 카드.
- 서브 포맷(로테이션): 「사요마요 판정쇼」(증거 3개 제출→판정봉), 「6개월 뒤의 나」(산 후 미래의 내가 보내는 영상편지).

## 4. 실행 로드맵·비용·성공 지표

| 주차 | 마일스톤 | 담당 |
|---|---|---|
| 이번 주 | 힉스필드 API 키 발급 확인 → Casto v1(씬 클립+2벌 렌더) 구현 · 수노 BGM 10곡 제작→라이브러리 등록 · 채널 3개 개설(사요마요/담아봄/클립) | 키·채널·BGM=사용자, 구현=Claude |
| +1주 | Make 시나리오 2개(유튜브·인스타 자동 게시) 연결 → **완전 자동 가동** · 컨셉 A/B(속마음 vs 판정쇼) 시작 | Claude(Make 구축), 인스타 비즈니스 전환=사용자 |
| +2~4주 | 주간 트렌드×실적으로 컨셉 승자 선정 · 네이버 클립 정례화 · 첫 파트너스 수익 추적 | 자동+주간 리뷰 |
| 15만원 달성 | 오픈 API 신청 → 딥링크 자동화·픽토 상품 엔진 가동(2단계 전환) | Claude |

- 추가 비용: **0원** (힉스필드·메이크·수노 기존 구독 활용, TTS·호스팅 무료) — 힉스필드 크레딧 소진 속도만 모니터링.
- 성공 지표: 4주 내 쇼츠 누적 조회 1만 / 픽담 소셜 유입 비중 20% / 첫 확정 수익 발생. 판정 기준 미달 시 컨셉 로테이션 교체(트렌드 스캔이 주간 단위로 근거 제공).
- 리스크: 힉스필드 API 상위 플랜 게이트(키 미발급 시 → 카드 스타일 유지+일레븐랩스 검토로 플랜 B), 인스타 API는 비즈니스 계정 필수, 파트너스 대가성 문구 누락 시 제재(자동 삽입으로 원천 차단).

**다음 액션 3개** — ①힉스필드 계정에서 API 키 발급 여부 확인(설정→API) ②유튜브 「사요마요」·인스타 「담아봄」 개설+비즈니스 전환 ③수노로 BGM 10곡(잔잔 5·경쾌 5) 생성해 전달. 이 3개가 오면 Casto v1 구현과 Make 연결을 바로 시작합니다.
