# 결제 등록 런북 — Veo(Google AI Studio) · ElevenLabs

famto는 키·카드를 만지지 않는다. 아래는 사용자가 **5분 안에** 끝내도록 클릭 경로만 적은 것.
(Google 절차는 2026-10-12 공식 문서 ai.google.dev/gemini-api/docs/billing 확인. ElevenLabs는 화면 이름이 바뀔 수 있음 ❓)

## A. Veo — Google AI Studio 유료 전환 (필수, 5분)

지금 쓰는 키(GitHub Secrets의 `LLM_API_KEY`)가 들어 있는 **프로젝트**를 유료 등급으로 올리면 끝. 키는 바꾸지 않아도 된다
(키는 프로젝트의 등급을 그대로 따른다).

1. https://aistudio.google.com/api-keys 접속(구글 로그인은 지금 키를 만든 계정).
2. 표에서 지금 키가 속한 프로젝트 행을 찾는다. **Billing Tier** 열의 **「Set up billing」** 클릭.
3. 처음이면: 국가 선택 → 약관 동의 → 연락처 → **결제 수단(카드)** 입력. 이미 결제 계정이 있으면 그걸 고른다.
4. **Prepay(선불) 최소 $5** 또는 Postpay(후불) 중 하나를 고른다. 선불이면 한도가 곧 손절선이라 **선불 $5~10 권장**
   (Lite 한 달 치 $70은 나중에 충전 — 파일럿은 $5면 충분).
5. 끝. famto에게 "결제 됐어" 한 줄. (키 재발급 불필요. 혹시 새 프로젝트를 만들었다면 그 프로젝트의 키를 Secrets에 넣는다.)

예산 가드는 코드에 있다(`veo.py`, 월 $70). 구글 쪽에도 안전장치를 하나 더: Google Cloud 콘솔 → 결제 → **예산 및 알림**에서
월 $80 알림을 켜 두면 이중 안전.

## B. ElevenLabs Starter ($6/월) — 선택, 3분

파일럿은 edge-tts(무료)로 먼저 본다. 목소리 연기가 필요하다고 판단되면 그때.

1. https://elevenlabs.io 가입(구글 계정) → Pricing → **Starter** 구독.
2. 프로필(왼쪽 아래) → **API Keys** → Create → 키 복사.
3. GitHub → Casto 저장소 → Settings → Secrets and variables → Actions → **New repository secret**
   이름 `ELEVEN_API_KEY`, 값 붙여넣기 → Add.
4. famto에게 "일레븐 넣었어" 한 줄.

## C. 하지 않아도 되는 것

- Google AI Pro/Ultra 구독(월 ₩29,000/249,000) — 앱용이라 우리 파이프라인엔 소용없다. API 결제만 하면 된다.
- Kling 구독 — Veo Lite로 간다.
