## 0. 3줄 요약

1. **쇼츠 광고 수익은 계산에서 지운다.** 한국 쇼츠 RPM 15~60원/1000뷰 → 월 9만 뷰 = 광고 수익 약 1,800원. 힉스필드 $59와 비교 자체가 성립 안 됨.
2. **돈은 객단가에서 나온다.** 지금 니치(생활·주방 1~3만원대)는 건당 300~600원. 같은 조회수로 **5~10만원대 이상 생활가전**을 다루면 건당 4,000~5,000원 — **조회수 그대로 5~8배**.
3. **진짜 목표는 「유튜브 쇼핑 제휴 프로그램」 자격이다.** 상품 태그가 영상에 직접 붙으면 설명란 링크와 클릭률이 자릿수 단위로 달라진다. 그리고 그 자격은 쇼츠 300만뷰가 아니라 **주간 롱폼 합본(자동 생성)으로 3,000 시청시간**을 채우는 게 40배 쉽다.

## 2. 수익 시뮬레이션 — 지금 설계로는 왜 안 되는가

전제: 하루 1편 × 월 30편, 편당 3,000뷰 = **월 9만 뷰**. 쿠팡 전환율 4%, 실효 요율 2%(가전은 1%).
쇼츠 설명란 → 외부 링크 CTR은 공개 벤치마크가 없어 **0.3%로 가정**(스와이프 중단→설명 열기→외부 브라우저, 3단 이탈).

| 시나리오 | 클릭 | 전환 | 건당 | 월 수익 |
|---|---|---|---|---|
| **A. 현재 설계** (생활·주방 3만원대, 설명란 링크) | 270 | 10.8건 | 600원 | **약 8,300원** (광고 1,800 포함) |
| **B. 객단가만 전환** (생활가전 40만원대, 설명란 링크) | 270 | 10.8건 | 4,000원 | **약 45,000원** |
| **C. + 유튜브 쇼핑 상품 태그** (앱 내 클릭, CTR 3% 가정) | 2,700 | 81건 | 4,000원 | **약 32만원** |

- 픽담 손익분기는 **월 쿠팡 판매액 77만원(≈수수료 2.3만원)**. → **A로는 손익분기도 못 넘고, B부터 넘는다.**
- A→B는 **코드 한 줄도 안 바꾸고 니치 정의만 바꾸면 되는 5배**다. 가장 싼 개선.
- B→C가 7배. 그래서 **모든 운영은 C의 자격 요건을 향해 정렬**되어야 한다.

### 2-1. 자격 요건 최단 경로 (여기가 이 문서의 핵심 발견)
유튜브 쇼핑 제휴 조건은 **둘 중 하나**만 만족하면 된다.

| 경로 | 요구치 | 환산 | 난이도 |
|---|---|---|---|
| 쇼츠 조회수 | 90일 **300만뷰** | 하루 33,000뷰. 1일 1편이면 편당 33,000뷰 | ❌ 신생 채널엔 비현실 |
| **롱폼 시청시간** | 12개월 **3,000시간** | 180,000분. 주간 합본 8분 × 평균 시청 25%(2분) = **9만 뷰**, 합본 52편 기준 **편당 1,730뷰** | ✅ **약 40배 쉬움** |

→ **「콕픽 위클리 — 이번 주 오늘의 콕 7개」 8분 롱폼 합본을 매주 자동 생성**한다. 이미 만든 쇼츠 7편을 ffmpeg으로 이어붙이고 인트로/아웃트로만 얹으면 끝(신규 제작비 0). 이게 상품 태그 자격으로 가는 유일한 현실 경로다.

## 3. 쇼츠 플롯 — 「콕 열리는 상자」 진단과 수정

### 잘 된 것
시리즈 템플릿·판정 구조·완주 유도(개봉 보상)·부정어 금지. 유지.

### 냉정한 문제 3가지

**① 훅이 약하다.** "오늘의 콕: 음식물처리기"는 정보 고지지 훅이 아니다. 스와이프를 멈추는 건 제품명이 아니라 **금액과 충돌**이다.
→ 첫 자막을 **가격 + 질문**으로: `"42만원. 이거 살까?"` → 0.8초 뒤 제품명 스탬프. 낚시가 아니면서 훅이 선다.

**② 매번 열리면 긴장이 죽는다.** 3편만 보면 "어차피 열리네"가 학습된다. 그러면 **완주 유도 장치 자체가 무력화**된다.
→ **'다음콕' 비율을 25~30%로 의도적으로 유지.** 이건 재미 장치이자 신뢰 자산이다(다 사라는 채널 = 광고 채널).

**③ CTA에 이유가 없다.** 영상에서 결론이 이미 났는데 왜 픽담에 가나.
→ **정보 격차를 설계로 남긴다.** 콕 3개는 영상에서 통과시키되, **4번째 변수 하나를 일부러 영상 밖에 둔다.**
   예: `"①②③은 통과. 근데 A/S 조건 하나가 걸려요 — 그건 픽담에."` / `"같은 가격대 3개 비교표는 픽담에."`
   → 이게 있어야 픽담 유입이 실제로 발생하고, 픽담에서 쿠팡 정식 위젯으로 전환된다(설명란 링크보다 안전·고전환).

### 수정 플롯 (15초 확정안)

| 초 | 내용 |
|---|---|
| 0~1.5 | **가격 훅** — "42만원. 이거 살까?" + 콕이 + 가격 스탬프 → 제품명 공개 |
| 1.5~3 | 룰 — "콕 3번 통과하면 열립니다" |
| 3~11 | **콕! ×3** — 근거 1줄씩(①비용 ②크기·설치 ③실사용 조건), 우드블록 |
| 11~13.5 | 판정 — 개봉(오늘의 콕/조건콕) 또는 도리도리(다음콕) |
| 13.5~15 | **정보격차 CTA** — "빠진 조건 하나는 픽담에" + 고정댓글 링크 |

### 서브 포맷 우선순위 (알고리즘·전환 기준 재정렬)
1. **「몇콕이면 살까?」** — 댓글 유도가 가장 강함(2026 알고리즘은 공유·참여 가중). **주 2회로 승격.**
2. **「재심콕」**(다음콕 제품이 가격 인하로 재등장) — 특가는 전환율이 압도적 + 연속 서사. **가격 추적 자동화되면 최우선.**
3. **「콕이 vs 콕이」** — A vs B 검색 수요 직격. 주 1회.
4. **「만원콕」** — 조회수 미끼용. 주 1회. 쿠팡 24시간 쿠키로 타 상품 구매까지 잡히는 보너스가 있어 완전히 버리지는 않는다.

### 발행량 상한 (양산형 정책 방어)
동일 템플릿 **하루 1~2편 + 주간 롱폼 합본 1편**이 안전선. 하루 3편 이상 동일 구성 반복은 '양산형 콘텐츠' 판정 위험. 콕이·자체 근거·판정 분기가 있으므로 이 선을 지키면 "최소 가공 재사용"에 해당하지 않는다.

## 4. 인스타그램 — 냉정한 결론: **2순위, 그리고 링크트리는 쓰지 마라**

### 왜 2순위인가
- 인스타는 외부 링크가 프로필 1개. **릴스 → 프로필 → 링크허브 → 쿠팡 = 4단 이탈.** 쇼츠 설명란보다 CTR이 더 나쁘다.
- 많은 계정이 링크트리·인포크링크 방식을 쓰는 건 **그게 잘 벌려서가 아니라 다른 수단이 없어서**다. 그 방식으로 유의미하게 버는 계정은 대부분 팔로워 수만~수십만의 협찬·공구 계정이고, 쿠팡 링크는 거기 붙는 부수입이다. **팔로워 0에서 시작하는 계정의 주 수익원이 될 수 없다.**
- 쿠팡파트너스 정지 사유에 **"비공식 단축 URL"**과 **"미등록 채널 홍보"**가 명시돼 있다. 링크허브 서비스를 한 겹 끼우는 건 굳이 회색지대를 밟는 것이다.

### 그래서 어떻게 하나 — 링크허브를 **픽담 페이지로 대체**
> 프로필 링크 = `pickdam.com/today` (오늘의 콕 아카이브 페이지)

이게 링크트리보다 나은 이유 3가지:
1. **정책 안전** — 외부 단축·리다이렉트 서비스를 안 거친다. 쿠팡 링크는 픽담 내 정식 위젯으로만 노출.
2. **자산 축적** — 같은 클릭이 링크트리로 새는 대신 픽담 트래픽이 된다(SEO·애드센스 라인과 합산). 링크트리는 남의 자산, 픽담은 내 자산.
3. **전환 구조** — 픽담 글은 이미 비교·조건분기가 있어 쇼츠보다 전환 설계가 낫다.

**→ 인포크링크/링크트리 도입은 하지 않는다.** 필요한 건 픽담에 "오늘의 콕" 인덱스 페이지 하나뿐이며, 이건 픽토 세션 영역이므로 inbox로 요청한다.

### 인스타 채널 컨셉 (투자 상한선 포함)
- **계정명: @kokpick.kr 하나로 통일.** '담아봄' 별도 브랜드는 반대 — 팔로워 0에서 브랜드를 둘로 쪼개는 건 순손실. 콕이·판정어·콕 게이지가 이미 유튜브와 공유되므로 인지 자산이 합산된다.
- **컨셉: "매일 하나, 살까 말까를 대신 판정해주는 택배상자".** 리뷰 계정이 아니라 **판정 계정**으로 포지셔닝(리뷰는 실물이 있어야 하고 레드오션, 판정은 근거만 있으면 됨).
- **콘텐츠 3종 (전부 기존 소재 재활용, 신규 제작 0)**
  1. **릴스(20초)** = 쇼츠 그대로 + 마지막 3초를 '오늘의 콕 카드'로 교체 → 저장 유도.
  2. **피드 정물 카드 1장** = 제품 + 가격 + 콕 3줄 + 판정 도장. 인스타는 저장(save)이 강한 신호라 카드형이 유리하고, **캐러셀 없이 1장**이 제작비 0.
  3. **스토리** = 매일 판정 스티커 + 링크 스티커(픽담). 팔로워 수 무관하게 링크 사용 가능.
- **투자 상한(엄수): 인스타 전용 기획·전용 촬영 금지.** Make 자동 게시로 한계비용 0을 유지한다. 인스타에 별도 시간을 쓰는 순간 유튜브 쇼핑 자격이라는 본선에서 멀어진다.
- **인스타를 하는 진짜 이유**(수익이 아님): ①한계비용 0 ②저장 자산 축적 ③협찬·공구 제안 유입 창구 ④검색 샌드박스와 무관한 픽담 유입.

## 5. 니치 재정의 (가장 싼 5배)

> **현재: "생활·주방"(1~3만원대) → 변경: "5만~100만원대 생활가전 구매 판정"**

- 「콕 3번」은 **고관여·고가 제품의 구매 결정 근거를 압축하는 포맷**이다. 3만원 실리콘 주걱에 콕 3번은 과잉이고, 40만원 음식물처리기·건조기·로봇청소기·에어컨엔 정확히 들어맞는다.
- 요율은 1%로 떨어져도 건당 수수료가 5~8배. 조회수 대비 수익이 뒤집힌다.
- 검색 의도도 유리: "○○ 살까 말까", "○○ 후회" 같은 고관여 쿼리는 저가 생활템보다 **구매 직전 단계**다.
- 저가 라인은 버리지 말고 **「만원콕」 주 1회**로 남긴다(조회수 미끼 + 24시간 쿠키 보너스).
- `casto.json`의 `niche`와 `trends.queries`를 이 방향으로 교체할 것. ← **다음 작업 1순위**

## 6. 비용·손절 라인 재설정

- **힉스필드 $59는 매달 낼 이유가 없다.** 클립뱅크 A~E는 1회성 자산이다. 첫 달에 12~15클립을 전부 뽑고 **즉시 해지**해도 파이프라인은 돈다(신규 클립은 분기 1회 재구독으로 충분). → 실질 비용 **$59 × 1회**.
- **기존 손절 라인("4주 내 조회 1만 미달 시 재검토")은 폐기.** 기준이 조회수 절대값이라 방향이 틀렸다.
  → **새 기준: 8주 시점에 ①최근 7일 평균 편당 1,000뷰 이상 ②쿠팡 클릭이 실제로 발생 ③구독 100명 이상.** 세 개 중 2개 미달이면 포맷을 의심하고, 3개 다 미달이면 채널 전략을 재검토한다.
- **마일스톤(이 순서로만 본다)**: 구독 500 → 주간 합본으로 시청시간 3,000h → **유튜브 쇼핑 제휴 승인** → 상품 태그 전환 → 그때부터 조회수가 돈이 된다.
