## 1. 메인 포맷: 「콕 열리는 상자」 (15초, 데일리 앵커)

**한 줄 규칙: 상자는 콕 3번을 통과해야만 열린다.**

| 초 | 화면 | 소스 |
|---|---|---|
| 0–0.5 | 콕이 클로즈업, 겉면에 오늘 제품 스탬프+제품명 자막 "오늘의 콕: 음식물처리기" (즉답, 낚시 아님) | 클립뱅크 A |
| 0.5–3 | 손가락 등장, 콕이 긴장→기대 표정. 자막 "콕 3번 통과하면 열립니다" | 클립뱅크 B |
| 3–11 | **콕! ×3** — 콕마다 근거 1줄(①월 전기료 ②크기·설치 ③실사용 조건). 콕 사운드=우드블록(사운드 브랜딩). 상자가 콕마다 말랑하게 눌림 | 클립뱅크 C + 자막 카드 |
| 11–15 | 통과 → 팟! 개봉, 제품 미니어처 뿅+종이 꽃가루, 도장 "오늘의 콕 ✅" / 미통과 → 도리도리 "다음콕 📦" | 클립뱅크 D/E |
| 고정 | 설명란·고정댓글: 픽담 글 링크 + 대가성 문구 | 자동 |

### 냉정 검증 — 4기준
1. **존재하지 않는 폼**: 언박싱(사람 손·실물)·리뷰·판정쇼는 넘치지만, "조건을 통과해야만 열리는 캐릭터 상자" 게임 구조는 유튜브에 없음. 주간 트렌드 스캔이 유사 포맷 출현을 감시(출현 시 차별점 강화).
2. **완주**: '열리나 안 열리나'는 시청자가 끝을 봐야 해소되는 미결 구조(언박싱 심리의 캐릭터화). 제품명은 0.5초에 공개하므로 낚시 혐오와 충돌 없음 — 유보되는 건 '판정'뿐. 15초·3비트 리듬·마지막 2초 보상.
3. **시리즈**: 완전 템플릿 — 매일 바뀌는 건 스탬프·근거 3줄·판정뿐, 콕이는 불변 → 캐릭터 자산 축적. 내장 스핀오프: **재심콕**(다음콕 제품이 가격 인하 시 재등장 — 연속 서사), **계절콕**(장마 전 제습기), **만원콕**(가격대 시리즈).
4. **쿠팡 수익**: 콕 3개 = 구매 결정 근거 그 자체(픽담 글의 조건분기 섹션 재활용). "오늘의 콕"=구매 허가 신호라 전환 의도가 가장 높은 순간에 CTA("자세한 비교는 픽담, 설명란👇"). 다음콕도 "이런 분은 조건콕"으로 전환 여지 유지.

## 2. 힉스필드 퀄리티 설계 — 클립뱅크 방식 (크레딧 절약 핵심)

매일 생성하지 않는다. **재사용 클립 은행**을 만들고 조립만 매일 한다.

| 뱅크 | 내용 | 제작 |
|---|---|---|
| A. 등장 | 콕이 대기·두리번(2–3초, 표정 3벌) | 로고 이미지 → 힉스필드 image-to-video |
| B. 긴장 | 손가락 다가옴, 콕이 움찔(2초, 2벌) | 〃 |
| C. 콕 반응 | 콕 찍혀 말랑 눌림(1초, 3벌 — 3콕에 다르게) | 〃 |
| D. 개봉 팝 | 뚜껑 팟+꽃가루(2–3초, 2벌) | 〃 |
| E. 다음콕 | 도리도리+미소(2초) | 〃 |
- 초기 구축: 클립 12~15개 ≈ 힉스필드 크레딧 300~450 (1회성). 이후 **주 2~3클립만 신규**(신선도) ≈ 주 60~90크레딧 → Plus 월 1,200 내 여유.
- 제품 컷: 쿠팡 파트너스 제공 소재 → 나노바나나(Unlimited·크레딧 0)로 미니어처/스탬프화 → ffmpeg 합성. 실패·소진 시 현행 카드 스타일 자동 폴백(발행 중단 없음).
- 캐릭터 일관성: 로고 원본 이미지를 항상 참조 이미지로 사용(같은 콕이 유지).

## 3. 서브 포맷 (주 1~2회 로테이션, 동일 파이프라인)
- **「콕이 vs 콕이」**: 상자 2개 나란히 — 조건 자막("4인 가구")에 맞는 쪽만 열림. A vs B 비교 검색 수요 직격, 클립뱅크 그대로 2벌 배치.
- **「몇콕이면 살까?」**: "3만원이면 콕? 5만원이면 콕?" 가격 한계선 판정 — 댓글 참여("얼마면 콕?") 유도, 특가 알림과 결합 시 전환 최강.

## 4. 인스타 변형 (20초)
동일 소재 → 개봉 후 마지막 3초를 **'오늘의 콕 카드'**(파스텔 정물 1장: 제품+가격+한 줄)로 마무리 → 저장 유도. 캡션 "프로필 링크 → 오늘의 콕 자세히".

## 5. Casto 구현 매핑 (다음 스프린트)
1. `casto.json`: concept="kok_open", 판정어 3종, 클립뱅크 경로(assets/clips/)
2. `make_short.py`: build_script를 콕 3근거 구조로(픽담 글 조건분기→3줄 압축), ffmpeg 조립을 클립뱅크+자막카드 합성으로 확장, 유튜브 15s/인스타 20s 2벌 렌더
3. 클립뱅크 구축: 힉스필드에서 A~E 생성(로고 참조) — 1회 세션
4. 캡션 생성기: "오늘의 콕" 제목 규격 + 픽담 링크 + 대가성 문구 자동
5. Make 연동: 완성 mp4 → 유튜브/인스타 자동 게시
