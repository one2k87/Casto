## 2. 왜 "노출을 올리는 법"이 잘못된 질문인가

Shorts 피드에는 **클릭이 없다.** 썸네일을 보고 누르는 게 아니라 이미 재생되고 있는
영상을 계속 볼지 넘길지만 정한다. 우리 트래픽의 95.3%가 여기다.

알고리즘은 explore → exploit 두 단계로 돈다. 새 영상을 작은 시드 관객에게 먼저 보여주고,
그 그룹이 잘 보면 더 넓은 관객으로 올린다. 시드에서의 성적이 나쁘면 **거기서 멈춘다.**
그 성적을 결정하는 1순위 신호가 "본 사람 vs 넘긴 사람" 비율과 평균 조회율이다.

그래서 이 채널에서 노출은 독립 변수가 아니다.

```
노출 = f(시청률)
```

마케팅으로 노출을 밀어 올리는 레버는 우리에게 사실상 없고(광고 제외),
있는 레버는 전부 "시드 관객이 안 넘기게 만드는 것" = 영상 퀄리티다.
**그래서 아래 두 축은 대등하지 않다. 축 A가 8이고 축 B가 2다.**

## 3. 축 A — 영상 퀄리티

### A-1. 길이 — 가장 큰 레버 하나 (효과 特大 / 비용 小)

우리 영상은 62초와 74초다. 벤치마크는 15~30초에서 시청률 80%가 나오고,
**45초를 넘으면 급락**한다고 말한다. 우리는 그 선을 한참 넘겼다.

여기서 중요한 건 이게 취향 문제가 아니라 **산수**라는 점이다.

```
시청률 = 절대 시청시간 ÷ 영상 길이

지금:   13초 ÷ 74초 = 17.6%
길이만 25초로:  13초 ÷ 25초 = 52%   ← 내용을 하나도 안 고쳐도
```

**절대 시청시간을 1초도 못 늘려도, 길이를 줄이는 것만으로 시청률이 3배가 된다.**
그리고 시청률이 3배면 배포가 붙는다.

- 「콕픽 차트」 편은 **33초**로 이미 절반은 해결돼 있다.
- 남은 건 **데일리**다. 13씬 × (자막 42자 ÷ 8자/초 + 여백 0.4초) = 73초 구조다.

> **제안 A-1** 데일리를 **22~26초**로 재단한다. 씬 13 → 7, 자막 42자 → 24자.
> 상품 3개를 다루던 걸 2개로 줄이거나, 상품당 컷을 2개에서 1개로 줄인다.
> 차트 편은 33초 유지하되 컷을 더 쪼갠다(A-3).

### A-2. 첫 3초 — 두 번째 레버 (효과 大 / 비용 小)

이탈의 50~60%가 첫 3초에 일어난다. 지금 우리 데일리의 0초는 이렇다.

```
훅:  "이번 주 / 갑자기 많이 보이는 것 3"
1컷: "왜 갑자기?"
```

이건 **우리 채널의 사정**이지 시청자가 얻는 게 아니다. 니치 상위 영상들의 0초는
전부 시청자의 문제나 결과부터 던진다(§4-1의 제목 비교가 그대로 0초 구성이기도 하다).

> **제안 A-2** 0초에 **상품이 동작하는 실사진 + 결과 자막**을 놓는다.
> "왜 갑자기?"는 3초 뒤로 민다. 차트 편의 "이거 보신 적 있죠"는 질문형이라
> 지금 구조 중에서는 제일 낫지만, 1위 상품 사진 위에 얹혀 있으니 **그 사진을
> 제품이 일하는 장면으로** 고르는 것이 낫다.

### A-3. 컷 리듬 (효과 中 / 비용 小)

잘 되는 Shorts는 **2~4초에 한 번** 화면이 바뀐다. 새로움이 주의를 리셋하기 때문이다.
지금 차트 데모는 7컷 33초 = **컷당 4.7초**, 마지막 판정 컷은 6.1초다.

> **제안 A-3** 상품 한 칸을 2컷으로 쪼갠다 — ①순위+상품명(2초) ②판정+이유(2.5초).
> 같은 33초에 컷이 7 → 12가 되고 컷당 2.7초가 된다. 내레이션은 그대로 흐른다.

### A-4. 루프 (효과 中 / 비용 極小)

재생률이 10%만 붙어도 배포가 눈에 띄게 붙는다. Shorts는 끝나면 자동으로 다시 시작한다.

> **제안 A-4** 마지막 프레임을 첫 프레임과 **같은 구도**로 끝낸다.
> 차트 편이면 아웃트로 배경을 1위 사진으로 두고(이미 그렇다) 표지와 같은 크롭을 쓴다.
> 이어붙였을 때 끊김이 안 보이면 성공이다.

### A-5. 소리 — BGM·효과음 (효과 中 / 비용 中)

지금 우리 영상에는 **TTS 내레이션만 있고 배경음이 없다.** 조용한 구간이 그대로
빈 소리로 들린다. 다만 정직하게 말하면, 조사한 자료들은 음악이 리텐션의 **보조**이지
주인이 아니라고 말한다 — "리텐션은 오디오 선택보다 시각적 리듬과 콘텐츠 품질에 더 의존한다".

> **제안 A-5** 저작권 안전한 트랙 **한 개를 채널 시그니처로 고정**하고
> 컷 전환에 짧은 효과음(0.1초)을 넣는다. 매번 다른 곡을 쓰면 브랜드가 안 쌓인다.
> 유튜브 오디오 보관함이면 저작권·수익화 모두 안전하다.
> **우선순위는 A-1·A-2 다음이다.** 길이가 74초인 채로 BGM을 깔아봐야 안 본다.

### A-6. 클레이 애니메이션의 자리 (효과 小~中 / 비용 中)

어제 넣은 눈 깜빡임은 좋은 진전이지만, **리텐션의 주범은 아니다.**
그리고 우리에겐 이미 실측이 있다 — 의인화·캐릭터가 상품을 소개하는 쇼츠는
1천~2.7만 회로 전멸했고, 실사진이 화면을 채운 것이 100만~473만이었다.

> **제안 A-6** 애니메이션 예산을 **판정 순간 한 컷**에만 쓴다.
> 콕이는 화면의 주인이 아니라 관객 대리인으로 구석에 남는다.
> 상품은 계속 실사진 정지다. 이 규칙은 바꾸지 않는다.

## 4. 축 B — 마케팅

### B-1. 제목 — 이 축에서 가장 큰 것 (효과 中 / 비용 極小)

Shorts 피드에서 제목은 CTR을 만들지 않지만 **검색·추천 분류**와 재생 후 인상을 만든다.
그리고 우리 제목은 지금 두 가지가 동시에 틀렸다.

**우리가 쓴 제목**

```
요즘 이거 다시 유행한다는 자동회전 냄비
요즘 이거 다시 유행한다는 주방템 3가지     ← 같은 템플릿
어쩐지 자꾸 보이더라, 요즘 난리난 주방템 TOP3
```

**같은 니치에서 이긴 제목** (우리 수집 데이터의 국내 상위 영상)

| 제목 | 무엇을 말하는가 |
|---|---|
| 좁은 주방이 **2배** 넓어지는 마법의 틈새 선반 | 결과를 숫자로 |
| **9천원대로** 이게 된다고?😳 넘침 걱정을 덜어주는 아이디어 뚜껑 | 가격 + 놀람 |
| 라면 넘치는 거 **이제 끝입니다** | 일상 짜증의 종결 |
| 사과 깎기 귀찮다면? 자동으로 껍질까지 싹! | 문제 → 해결 |
| 부자들이 계란 먹는 신박한 방법ㄷㄷ | 호기심 갭 |

차이가 분명하다. 이긴 제목은 **시청자의 문제·결과·가격**을 말하고,
우리 제목은 **"유행한다"**는 우리 쪽 사정을 말한다. 시청자가 가져갈 게 없다.

참고로 편당 조회수는 「주방 슬라이딩 선반」이 143,400회, 우리는 62.5회다.

> **제안 B-1** 제목 규칙을 셋으로 고정한다.
> ① 상품이 해결하는 **문제나 결과**를 먼저 쓴다 ② **숫자나 가격**을 하나 넣는다
> ③ "요즘 유행"이라는 말은 제목에서 뺀다(그건 본문에서 태그가 말한다).
> 그리고 같은 템플릿을 연속 2편에 쓰지 않도록 코드로 막는다.

### B-2. 검색 자산 (효과 中 / 비용 小 / 복리)

검색 유입 4.7%, 그마저 검색어가 무관하다. Shorts도 검색 결과에 들어가고,
이건 **시간이 지나도 죽지 않는 유일한 유입원**이다.

> **제안 B-2** 키워드 밀도 규칙 — 제목 1회 / 설명 2회 / 태그 5회 이상.
> 상품의 **정식 상품명**(검색되는 이름)과 **통칭**(피드에서 부르는 이름)을 둘 다 넣는다.
> 차트 편 설명란은 이미 순위·이유·가격·링크 구조라 여기에 붙이기 쉽다.

### B-3. 크로스 포스팅 (효과 中 / 비용 小 — 자동화 가능)

같은 파일을 인스타 릴스·틱톡에 올린다. 유튜브는 멀티 플랫폼 공유를 불리하게 보지 않고,
오히려 외부 유입이 초기 시드 성적을 올린다. Make 시나리오가 이미 유튜브에 올리고 있으니
같은 자리에서 분기를 하나 더 다는 일이다.

> **제안 B-3** 릴스·틱톡 자동 업로드를 Make에 추가한다. 캡션은 플랫폼별로 다르게.
> 다만 **9/20 이후**에 한다 — 지금은 시청률 17%짜리를 세 곳에 뿌리는 게 된다.

### B-4. 시리즈 구조 (효과 中 / 비용 極小)

「콕픽 차트」는 이미 시리즈다. 일요일 고정, 5위부터 카운트다운, 다음 주 예고까지 있다.
여기에 붙일 것은 **재생목록**뿐이다.

> **제안 B-4** 「콕픽 차트」 재생목록을 만들고 모든 차트 편을 넣는다.
> 설명란 첫 줄에 재생목록 링크. 한 편을 본 사람이 두 번째 편으로 가는 유일한 길이다.

### B-5. 참여 0 (효과 小~中 / 비용 極小)

좋아요 0 / 125회. 건강 기준은 3~6%다. 참여는 알고리즘 신호이기도 하다.

> **제안 B-5** 마지막 컷에 **질문 하나**를 남긴다. "이 중에 써보신 거 있나요?"처럼
> 답이 한 단어로 나오는 것. 지금 아웃트로의 "심사받고 싶은 제품은 댓글로"는
> 요구가 커서 답하기 어렵다.

### B-6. 픽담 링크 (효과 小 / 비용 小 — 신뢰 문제)

설명란의 픽담 링크가 `latest_post()`로 **그냥 최신 글**을 가리킨다.
영상과 무관한 글로 보내면 한 번 속은 사람은 다시 안 누른다.

> **제안 B-6** 영상의 상품과 실제로 연결된 글이 없으면 **링크를 빼는 쪽**이 낫다.

**1·2·3만 해도 시청률이 한 자릿수에서 50% 근처로 간다.** 나머지는 그 뒤의 이야기다.

## 6. 무엇을 보고 성공을 판단하나

주마다 볼 숫자는 **딱 하나, 평균 조회율**이다. 조회수는 후행 지표라 먼저 움직이지 않는다.

| 주 | 목표 평균 조회율 | 못 넘기면 |
|---|---|---|
| 9/20 주 | 35% | 길이를 20초로 한 번 더 줄인다 |
| 9/27 주 | 50% | 포맷(카운트다운 구조)을 의심한다 |
| 10월 | 60%+ | 여기부터 조회수가 따라 올라온다 |

좋아요/조회 3%를 넘기면 그때 크로스 포스팅으로 시드를 넓힌다.
