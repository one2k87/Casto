2. Make → 시나리오 `콕픽_유튜브_자동게시` → History → 빨간 실행(10/15) 클릭 → 모듈 4(YouTube) 말풍선 클릭 → 오류 본문(reason 문구)을 famto에게 붙여넣기.
   403의 세부 reason(`quotaExceeded` / `forbidden` / `forbiddenPrivacySetting` / `uploadLimitExceeded`)에 따라 고치는 방법이 전혀 다르다.
3. 유튜브(픽핸드 브랜드 계정 메일)에 10/11~13 사이 경고·기능 제한 안내가 왔는지 확인.
